# Future Interns - Task 1
## Business Sales Performance Analytics

### Project Overview
This project analyzes the Sample Superstore sales dataset to identify
sales trends, profitable categories, high-performing regions, and
top-selling products.

### Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- VS Code

### Key Metrics
- Total Sales: $2,297,200.86
- Total Profit: $286,397.02
- Profit Margin: 12.47%
- Total Orders: 5,009
- Unique Customers: 793
- Total Quantity Sold: 37,873

### Key Insights
1. Technology has the highest sales and profit.
2. West region has the highest sales and profit.
3. Canon imageCLASS 2200 Advanced Copier is the top-selling product.
4. Overall profit margin is approximately 12.47%.
5. Furniture has the lowest profit among the three categories.

### Business Recommendations
1. Focus more on high-performing Technology products.
2. Expand sales strategies in the West region.
3. Investigate low-profit Furniture products and pricing.
4. Promote high-profit products to increase overall profit.
5. Monitor monthly sales trends for inventory and promotions.
